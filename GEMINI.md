# Project instructions

This is an Astro website deployed through GitHub Pages.

## Stack

- Astro
- TypeScript
- pnpm
- GitHub Pages
- Tailwind CSS

## Safety

- Inspect git status before editing.
- Never commit or push automatically.
- Never use git reset --hard.
- Never expose API keys or secrets.
- Preserve the GitHub Pages base path.
- Run pnpm build after changes.
- Fix build errors before finishing.

## Development

- Prefer reusable Astro components.
- Avoid React unless real interactivity requires it.
- Keep client-side JavaScript minimal.
- Use semantic and accessible HTML.
- Make every section responsive.
- Use Tailwind CSS consistently.

## Design

- Use the frontend-design skill when creating or redesigning interfaces.
- Use the web-design-guidelines skill when reviewing the final result.
- Create a premium editorial visual identity.
- Avoid generic AI purple-gradient designs.
- Avoid excessive glassmorphism and glowing blobs.
- Use strong typography, spacing, contrast, and hierarchy.
- Make mobile layouts feel intentionally designed.

## Workflow

Before changing files:

1. Inspect the current project.
2. Explain weaknesses.
3. Propose a design concept.
4. List files to be changed.
5. Wait for approval.

After changing files:

1. Run pnpm build.
2. Fix errors.
3. Summarize changed files.
4. Show git status.
5. Leave commit and push to the user.
