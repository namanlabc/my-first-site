# Naman.blog contributor instructions

Before changing any UI, layout, copy, illustration, featured image, icon, project presentation, or social graphic, read [`BRAND.md`](BRAND.md) completely and treat it as the visual source of truth.

Preserve all post slugs, canonical URLs, metadata, RSS, sitemap, accessibility, dark/light modes, and GitHub Pages behavior. Test UI changes at 360 px and 1440 px, confirm there is no horizontal overflow, and run the production build.

Do not turn the site into a startup landing page, generic developer portfolio, dashboard, or card wall. Prefer real projects, writing, and personal details over decorative claims.
